# Bible Cross-Reference Index

A browsable index of all 344,799 Bible cross-references, organized by book and chapter. Each verse lists the passages it points to, strongest first, and every reference links to the passage text on BibleGateway.

**Live page:** https://Liberty-Pro.github.io/bible-cross-reference-index/

## Features
- Browse 66 books in 8 sections (Law, History, Poetry, Major Prophets, Minor Prophets, Gospels & Acts, Letters, Revelation)
- Jump to a passage with the search box (for example "John 3:16" or "Psalm 119")
- Filter by minimum votes, by the section a reference points to, or to Old Testament to New Testament links only
- Overview table showing how many references run between each pair of sections
